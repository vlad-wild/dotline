# dotline

Переезд с Windows 11 на Arch Linux (ASUS Zenbook 14 UX3405CA) с рабочим
столом в стиле Nothing OS: niri + Quickshell, монохром с одним красным
акцентом, точечный шрифт, вход по лицу через собственный проект
[faceauth](https://github.com/vlad-wild/faceauth).

**Статус: в разработке, ещё не запускался на реальном железе.** Весь этот
репозиторий написан и проверен (синтаксис, баланс скобок, логика —
численно и на тестовых данных, несколько мест — по официальной
документации использованных API) на Windows, без доступа к Linux с
Wayland. Первый настоящий прогон — на ноутбуке, после `./install.sh`.
Скриншотов пока нет: системы, которую можно было бы сфотографировать, ещё
не существует — появятся после первой установки.

## Что уже готово

- **Палитра из обоев** — `dotline-wallpaper`/`dotline-theme`/`palette-post`: обои → matugen → красный акцент на монохромных обоях → перекраска kitty/GTK/fuzzel/niri.
- **niri + Quickshell шелл** — бар (меню в стиле macOS, рабочие столы, статус), лаунчер, уведомления, OSD громкости/яркости/профиля питания, быстрые настройки Wi-Fi/Bluetooth, шпаргалка клавиш.
- **Вход по лицу** — экран блокировки с параллельной проверкой лица (`faceauthd`) и паролем, polkit-агент, графический greeter при загрузке. PAM-файлы вставляются точечно, не затирая чужие (`/etc/pam.d/sudo`).
- **Перенос из Windows** — `scripts/migrate`: BitLocker, rsync данных и сохранений игр, импорт Wi-Fi-профилей.
- **Мышь MX Master 4** — жесты через Solaar.
- **Телефон (KDE Connect)** — глиф в баре, меню `Mod+K`: сопряжение, найти телефон, пинг, файлы (`docs/phone.md`).
- **Окно настроек** (`Mod+Comma`) — пока только «Оформление» (тема, обои) и «О системе»; «Лицо» открывает отдельное приложение `faceauth-ui`, а не дублирует его.
- `install.sh` / `update.sh` / `uninstall.sh` — манифест всего, что поставлено, для чистого отката.

Подробный разбор того, что сделано и с какими оговорками, — в
[MIGRATION.md](MIGRATION.md) и истории правок; список того, что ещё не
делалось (окно настроек, eGPU, тачпад-жесты, камера), — в конце этого
файла.

## Установка

Сначала — разметка диска и сама система: [docs/install-arch.md](docs/install-arch.md).
Дальше:

```sh
git clone <этот репозиторий> ~/dev/linux-migrate
cd ~/dev/linux-migrate
./install.sh --dry-run   # посмотреть, что будет сделано
./install.sh
```

После установки — запись лица (`sudo faceauth add -u $USER`) и перенос
данных ([MIGRATION.md](MIGRATION.md), `dotline-migrate mount`).

Обновление: `./update.sh`. Полный откат: `./uninstall.sh --dry-run`, затем
`./uninstall.sh`.

## Структура

```
dotfiles/     конфиги, которые stow раскладывает в $HOME
  niri/       компоновщик — config.kdl, colors.kdl (генерируется)
  quickshell/ сам шелл: бар, лаунчер, лок-скрин, polkit, уведомления, OSD
  kitty/ fuzzel/ gtk-*/ qt6ct/ starship/ fastfetch/ solaar/
system/       копируется в / как есть: PAM, greetd, системный greeter
scripts/      dotline-wallpaper, dotline-theme, dotline-power, dotline-migrate, …
lib/          common.sh (манифест, --dry-run, PAM-вставка) и palette.sh
packages/     списки пакетов pacman/AUR по группам
docs/         install-arch.md, mouse.md
wallpapers/   обои по умолчанию
MIGRATION.md  перенос данных и приложений из Windows
```

## Что ещё не сделано

- **Окно настроек** — есть, но минимальное («Оформление», «Лицо», «О системе»); страниц «Экраны»/«Видеокарты» нет.
- **Несколько мониторов** — niri сам разумно раскладывает новый экран, но страницы управления профилями мониторов нет.
- **eGPU** (AMD RX 7900 GRE по Thunderbolt) — пакеты в `packages/egpu.txt`/`rocm.txt` есть, автоматизации подключения/отключения — нет.
- **Тачпад** — базовые жесты niri включены, расширенные (`--with-extra-gestures`) — нет.
- **Эффекты камеры/микрофона** — не делались (нужно железо под рукой, чтобы проверить портретный свет/замену фона на NPU).
- Функциональные клавиши Zenbook (Fn+ряд) не проверены на реальной клавиатуре.

Если что-то из этого нужнее остального — говорите, продолжим.
