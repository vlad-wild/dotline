# Медиаплеер

Глиф в баре (точки-эквалайзер + название трека) и карточка `media/MediaCard.qml`
(клик по глифу, `qs -c dotline ipc call media toggle`, или `/медиа` в лаунчере)
работают через `Quickshell.Services.Mpris` — то есть через протокол MPRIS
напрямую по D-Bus, без `playerctl` и без нового пакета: любое приложение,
которое само публикует MPRIS (Spotify, VLC, mpv с правильным флагом,
браузеры для вкладок с видео/аудио, Telegram Desktop), подхватывается само.

## Что внутри

- `services/Media.qml` — обёртка над `Mpris.players`. Если играет
  несколько источников сразу, активным считается тот, что реально
  **играет** (`playbackState === Playing`), а не последний выбранный
  вручную — ручной выбор (переключатель внизу карточки) учитывается
  только когда ничего не играет.
- Карточка: обложка (`trackArtUrl`, если плеер его отдаёт — не все
  отдают), название/исполнитель, перетаскиваемая полоска прогресса
  (`seekTo`, только если `canSeek`), play/pause/next/prev.
- Прогресс обновляется не рефлекторно: сам протокол (не Quickshell)
  **не шлёт событие на каждую секунду воспроизведения** — только таймер
  раз в секунду дёргает `positionChanged()` у активного плеера, пока что-то
  играет (так и задумано в самом MPRIS, не ошибка и не то, что можно
  починить с нашей стороны).
- Все элементы управления смотрят на `canXxx`/`xxxSupported` перед тем,
  как показать/применить действие — у разных плееров поддержка команд
  (seek, volume, shuffle) очень разная.

## Что не делал (из плана, по приоритету)

- **Визуализатор через `cava`** — не подключал; раздел плана описывал его
  как опциональный поверх карточки.
- **Синхронные тексты песен (LRCLIB)** — не делал, по плану это отдельная
  опция, по умолчанию выключенная.
- **Карточка на экране блокировки** — не перенёс `MediaCard`/показ трека
  на `lock/Lock.qml`, это отдельная интеграция.
- **Акцент палитры из обложки трека** — в плане это опция по умолчанию
  выключенная; не делал вообще.
- **Настоящая бегущая строка** для длинных названий — сейчас просто
  обрезается (`elide`), не скроллится.

## Не проверено

Разработка — на Windows без Wayland и без запущенного MPRIS-клиента под
рукой. Первая реальная проверка — на ноутбуке: `playerctl -l` (или сам
`qs -c dotline`) должен увидеть реальный плеер, карточка — показать его
трек и слушаться кнопок.
