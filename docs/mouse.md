# Logitech MX Master 4

Solaar (`packages/laptop.txt`) управляет мышью и обрабатывает жесты из
`dotfiles/solaar/.config/solaar/rules.yaml`. Сам Solaar запускается скрыто
(`spawn-at-startup "solaar" "--window=hide"` в `config.kdl`) — трей для его
иконки ещё не построен, так что окно показывать пока незачем.

## Разовая ручная настройка (один раз после подключения мыши)

Правила жестов срабатывают только на **отведённых** (diverted) кнопках —
это состояние Solaar хранит в собственном `~/.config/solaar/config.yaml`,
в формате, специфичном для железа и прошивки конкретной мыши. Этот файл
**не входит в dotfiles**: без самой мыши под рукой нельзя было проверить
точный формат, поэтому включается руками один раз:

1. `solaar show` (или обычное окно Solaar, если нужно видеть его один раз: `solaar`).
2. Найти устройство **MX Master 4** → вкладка **Key/Button Diversion**.
3. Включить **Diverted** для:
   - **Gesture Button** (кнопка под большим пальцем) — на ней висят жесты из `rules.yaml`;
   - любых других кнопок, которые захочется переназначить так же.
4. Перелогиниться или перезапустить Solaar (`pkill solaar && solaar --window=hide &`), чтобы `rules.yaml` подхватился.

После этого можно менять сами жесты, просто редактируя `rules.yaml` —
перезапуск Solaar не нужен, он сам видит изменения файла.

## Что уже настроено

Удержание **Gesture Button** + направление:

| Жест | Действие |
|---|---|
| Вверх | Обзор niri (`toggle-overview`) |
| Вниз | Лаунчер |
| Влево | Рабочий стол вверх |
| Вправо | Рабочий стол вниз |

Остальные кнопки (вперёд/назад, колесо SmartShift, DPI) оставлены как
есть — у них уже разумное поведение по умолчанию (навигация в браузере,
автопереключение плавная/шаговая прокрутка), а не переопределены специально
под этот рис.

## Батарея в баре, haptics

Заряд мыши показывается в баре через `services/BtService.qml`
(`BluetoothDevice.battery`/`batteryAvailable` — общий Bluetooth-сервис,
без специального кода под эту мышь). Хаптик-отклик самой MX Master 4
управляется только официальным Logi Options+ (Windows/macOS) — под Linux
штатного способа его настроить нет; `packages/laptop.txt` оставляет
комментарий на случай, если `solaar-git` когда-нибудь это исправит.

## Проверка

- `solaar show` — видит ли систему мышь и показывает ли реальные имена кнопок (могут отличаться от общих «Gesture Button», уточнить по выводу).
- Подержать Gesture Button и провести вверх/вниз/влево/вправо — должны сработать обзор/лаунчер/смена стола.
- `journalctl --user -u solaar 2>/dev/null` или просто вывод `solaar` в терминале — если жест не сработал, смотреть, не разъехалось ли имя кнопки с тем, что в `rules.yaml`.
