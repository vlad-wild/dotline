# Жесты тачпада

niri ≥ 25.05 включает жесты по умолчанию — настраивать нечего,
`dotfiles/niri/config.kdl` только задаёт общие параметры тачпада
(`tap`, `natural-scroll`, `dwt`, `clickfinger`).

| Жест | Действие |
|---|---|
| Свайп тремя пальцами влево/вправо | Перемещение по ленте окон на столе |
| Свайп тремя пальцами вверх/вниз | Переключение рабочего стола |
| Свайп четырьмя пальцами вверх/вниз | Обзор (`toggle-overview`) |

## Расширенные жесты — сознательно не подключал

Есть неофициальный форк **niri-tablet** (патчи поверх niri с настраиваемым
`gestures.kdl`, где любой жест можно привязать к любому действию, как
бинды клавиш). Не стал его подключать: это форк компоновщика, а не
отдельный пакет сверху — на повседневной системе с dual boot и входом по
лицу менять сам компоновщик на неофициальную ветку ради дополнительных
жестов того не стоит. Если захочется больше жестов позже — отдельное,
осознанное решение, не между делом.

## Проверка

На ноутбуке: три пальца влево/вправо и вверх/вниз, четыре пальца
вверх/вниз — должны работать сразу после установки niri, без всякой
дополнительной настройки.
